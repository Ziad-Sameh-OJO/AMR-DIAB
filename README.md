# PHANTOM · Happ portal

منصة مستقلة لإدارة مفاتيح الاشتراك وإعداد اتصال Happ عبر Hysteria2. الواجهة عربية مع خيار إنجليزي، ومعها لوحة إدارة محمية.

**الحالة الحالية:** التطبيق والاختبارات يعملان محليًا. تشغيل VPN على الهاتف يتطلب خادمًا ونطاقًا وشهادة TLS. مزايا تعديل Free Fire غير منفذة، وتظهر غير متاحة بدل تشغيل محاكاة على أنها نتيجة حقيقية.

## التشغيل المحلي

يلزم Node.js 22.16 أو أحدث (اختُبرت النسخة على Node 24). لا توجد حزم خارجية مطلوبة.

```sh
npm run setup
npm test
npm start
```

افتح `http://127.0.0.1:3000`، ولوحة الإدارة `http://127.0.0.1:3000/admin`.

- أمر setup ينشئ `.env` بصلاحيات خاصة دون طباعة الأسرار. كلمة مرور الإدارة هي قيمة `ADMIN_TOKEN` في هذا الملف.
- ادخل الإدارة وأصدر مفتاحًا، ثم انسخه؛ النص الكامل يظهر مرة واحدة ولا يُخزن في قاعدة البيانات.
- مدة الاشتراك تبدأ عند أول **قبول مصادقة VPN** بواسطة Hysteria، وليس عند فتح الموقع أو إنشاء الرابط. قبول المصادقة وحده لا يثبت مرور بيانات؛ الحالة المتصلة تأتي من قياسات الخادم.
- الربط يخص متصفح الدخول بواسطة معرف عشوائي. ليس بصمة عتاد ولا ضمان جهاز VPN واحد؛ استيراد Happ لا يدعم في هذه النسخة فرض جهاز واحد تشفيريًا.
- إعدادات السيرفر الفارغة تمنع توليد رابط مزيف أو عرض اتصال غير موجود.

## ما يعمل

- دخول الإدارة والعميل عبر جلسات HttpOnly؛ منع تعديل بيانات مستخدم آخر.
- مفاتيح عشوائية بـ128 بت، تخزين SHA-256 للمفاتيح، رفض أي مفتاح لم تصدره المنصة.
- إصدار وامتداد وإلغاء مفاتيح، وفك ربط المتصفح مع إبطال الجلسات وروابط VPN القديمة.
- رابط اشتراك مستقل لكل حساب؛ محتواه URI قياسي لـHysteria2 وفتح Happ عبر `happ://add/`، مع خيار نسخ الرابط.
- خدمة مصادقة VPN منفصلة على loopback؛ لا يكشفها خادم الويب العام.
- قياسات `/online` و`/traffic` من Hysteria؛ فشل القياسات يعرض «تعذّر تأكيد الاتصال».
- إلغاء الاشتراك يمنع اتصالًا جديدًا فورًا ويحاول فصل القائم عبر `/kick`. المراقب يعيد محاولة فصل المنتهي/الملغى كل 15 ثانية. إذا تعطل مسار التحكم، **لا نضمن فصل النفق القائم فورًا**؛ الواجهة توضح أن الفصل لم يتأكد.
- حماية الوصول للملفات، CSRF، تحديد حجم الطلبات ومعدل المحاولات، وإخراج نصوص المستخدم بشكل آمن.

## الملفات والبيانات

- `server.js` و`lib/`: التطبيق الجديد؛ `src/app.js` و`public/admin.js`: الواجهات الجديدة.
- `.env`: الأسرار والإعداد. لا يُرفع إلى Git.
- `data/runtime/database.json`: تخزين خاص مستقل بكتابة ذرية وصلاحيات 600، ومفاتيح مجزأة وجلسات وسجل عمليات. يُستبعد من Git. فساد الملف يمنع التشغيل؛ لا يعيد تفعيل حسابات تجريبية.
- `data/database.json` و`data/db.js` القديمان محفوظان دون تعديل، ولا يقرأهما التطبيق الجديد ولا يقدمهما HTTP. المفاتيح القديمة لا تُرحَّل تلقائيًا؛ تحتوي النسخة القديمة عينات ومسارات قبول غير موثوقة.
- `src/engine/*` و`src/config.js` و`src/translations.js` ملفات قديمة محفوظة للمرجع، لا يشغّلها التطبيق الجديد ولا يقدمها خادم الملفات. لا تمثل محرك لعبة فعليًا.
- التقرير العربي الموجود مسبقًا لم يُعدل.

**حدود التخزين:** هذه نسخة أولى لخادم واحد وعملية Node واحدة. لا تشغل replicas أو PM2 cluster على نفس ملف البيانات. قبل التوسع، انقل العمليات إلى PostgreSQL ومعاملات ومخزن جلسات/حدود موزع. خذ نسخًا احتياطية مشفرة من قاعدة البيانات وAPP_SECRET مع اختبار استعادة. تغير APP_SECRET يبطل روابط الاشتراك والـVPN الحالية.
