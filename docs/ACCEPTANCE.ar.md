# ما اختُبر وما تبقى

## اختبارات محلية آلية

`npm test` يختبر HTTP حقيقيًا على loopback مع قواعد بيانات مؤقتة مستقلة، وخادم اختبار يحاكي عقد Hysteria Stats API فقط. لا يتصل بأي خادم لعبة أو حساب مستخدم خارجي.

يغطي رفض المفاتيح غير الصادرة وأسماء التجاوز القديمة، عزل الإدارة، منع ملفات المشروع والأسرار، خصائص cookies، حفظ hash للمفاتيح، حماية الطلبات من المصادر الخارجية، تحديد المعدل والحجم، ربط المتصفح، تدوير روابط الاشتراك، الإلغاء والتجديد والانتهاء، بدء المدة عبر مصادقة VPN فقط، شكل URI، فصل أنواع tokens، حالات القياسات وفشلها، الصيانة، الخروج، فساد قاعدة البيانات، ومنع مزايا اللعبة غير المنفذة.

## قبل إطلاق VPN

هذه الاختبارات تحتاج السيرفر والهاتف، ولم تُستبدل بنتائج الاختبارات المحلية:

1. TLS صالح على الموقع وHysteria، ولا يظهر تحذير أو حاجة لتجاوز الشهادة.
2. إضافة الرابط في Happ على iOS، ونسخ الرابط كطريقة احتياطية، وتحديث الاشتراك لاحقًا.
3. نجاح TCP وUDP وDNS عبر النفق على وجهة اختبار تملكها، ومراجعة عنوان الخروج.
4. بدء المدة مرة واحدة عند أول قبول مصادقة، واستمرارها بعد إعادة تشغيل العميل والخادم.
5. البيانات المعروضة في الموقع تتبع `/online` و`/traffic` فعليًا؛ توقف القياسات يعرض Unknown؛ إغلاق Happ يعرض Offline بعد القياس التالي.
6. إلغاء المفتاح يمنع تنزيل الاشتراك ويمنع اتصالًا جديدًا ويُسقط النفق القائم. تكرار الاختبار مع تعطل Stats API للتأكد من ظهور عدم تأكد الفصل ثم إعادة محاولته بعد التعافي.
7. انتهاء مدة مفتاح أثناء جلسة فعلية ثم فصله خلال دورة المراقبة التالية عند سلامة مسار التحكم.
8. لا يمكن الوصول عبر النفق إلى 127.0.0.1 أو عناوين الشبكات الخاصة أو API القياس/المصادقة أو metadata الاستضافة.
9. نسخ احتياطي واستعادة، تجديد شهادة، إعادة تشغيل الخدمات بعد reboot، واختبار انقطاع الشبكة.
10. مقارنة تجربة اللعبة يدويًا بين VPN والاتصال المباشر. لا ضمان بتحسن latency ولا إثبات لتعديل التصويب من اتصال VPN.

Marker وAimpoint وAim Lag وGloo Rotation وFast Revive **غير منفذة**؛ لا نعتبرها ناجحة أو قابلة للاختبار بمجرد ظهورها في الواجهة. الملفات السابقة التي تصف packet interception بقيت خارج runtime للمرجع.
